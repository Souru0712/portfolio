If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

## Quick reference

- **Vibe:** terminal-inspired, dark mode, monospace headings, neon-green accent, calm and precise.
- **Tokens:** `colors_and_type.css` — import at top of any HTML file.
- **Voice:** lowercase, terse, em-dashes, no emoji, code-comment kickers (`// 01 · about`).
- **Components:** see `ui_kits/portfolio/` for production-quality JSX components.
- **Logo / glyph:** `assets/wordmark.svg`, `assets/glyph.svg`, `assets/favicon.svg`.
