# Portfolio UI Kit — Oscar DE

Single-product UI kit: a personal portfolio website with the 5 required sections (About, Projects, Skills, Resume, Contact). Built as a single-page scrollable site with a sticky nav and terminal-style hero.

## Files
- `index.html` — entry point, loads React + all components
- `Nav.jsx` — sticky top navigation
- `Hero.jsx` — about-me hero with typewriter
- `Projects.jsx` — projects grid with filterable tags
- `Skills.jsx` — skills bucket display
- `Resume.jsx` — resume preview + download CTA
- `Contact.jsx` — contact methods + message composer

All components share the `colors_and_type.css` token file at the repo root.
